# 🍋 The Lemonade Cash  
### App de administración de préstamos semanales (Streamlit + SQLite)

**The Lemonade Cash** es una aplicación ligera, rápida y creada para administrar préstamos personales con pagos semanales a 12 semanas y un interés fijo del **50%**.  
Funciona completamente en la nube usando **Streamlit Cloud**, sin necesidad de instalar nada en tu computadora.

---

## 🚀 Características principales

### ✔ Registro de clientes  
Incluye:
- Nombre completo  
- Teléfono (llave única)  
- Dirección  
- Contacto de emergencia  
- Validación del cliente con checkboxes  

### ✔ Registro de créditos  
- Interés fijo del **50%**  
- Plazo de **12 semanas**  
- Cálculo automático del pago semanal  
- Fecha del préstamo configurable  

### ✔ Registro de pagos semanales  
- Buscar cliente por nombre o teléfono  
- Ver historial de pagos  
- Registrar nuevos pagos  
- Ver total pagado y saldo pendiente  

### ✔ Base de datos completa  
Todo se guarda en **SQLite**:
- Tabla de clientes  
- Tabla de créditos  
- Tabla de pagos  

---

## 🛠 Tecnología utilizada

- **Python**
- **Streamlit**
- **SQLite**

- **Streamlit Cloud (para deploy sin instalar nada)**
